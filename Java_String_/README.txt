Java String Practice Programs - No Comments

This ZIP contains Sample Program 1 and Level 1 Questions 1 to 10.
Each program is in a separate Java file.
No Java comments are included in the source code.

Compile and run any program:
    javac Q1_CompareStrings.java
    java Q1_CompareStrings

Change the file and class name in the commands for another question.

Note:
For Q6, Java's String.substring(start, end) throws an index exception
for invalid indexes. The program explicitly validates start > end and
throws IllegalArgumentException to demonstrate the exception requested.
