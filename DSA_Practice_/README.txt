DSA Practice Sheet - Solved (All Sections)

Files:
1. DSAComplexitySolutions.java
   - Java implementations of Linear Search, Iterative Binary Search, and Merge Sort.
   - Time and space complexity answers are included in Java comment lines.
2. Pseudocode_and_Flowcharts.txt
   - PC-1 and PC-2 pseudocode.
   - FC-1 and FC-2 text flowcharts.
   - Written explanations for all TC and SC questions.

How to compile and run:
    javac DSAComplexitySolutions.java
    java DSAComplexitySolutions

The program asks for a Linear Search target and a Binary Search target,
then displays the sorted result of Merge Sort.

Note: Binary Search uses the already sorted sample array.
